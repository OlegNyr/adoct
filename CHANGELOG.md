## [1.2.0]

Экспорт из Confluence в Markdown (GFM) наравне с AsciiDoc + улучшения выгрузки дерева.

- Второй формат экспорта — Markdown (GFM): выбор формата в IDEA-плагине и MCP-туле (`format`).
  Форматонезависимый AST, отдельный `MarkdownWriter` (alert-цитаты, HTML-фолбэк таблиц с
  colspan/rowspan/rich-ячейками, inline-HTML для подчёркивания/цвета).
- Перекрёстные ссылки между страницами выгружаемого дерева — локальные относительные пути на
  `index.adoc`/`index.md` (round-trip с публикацией), в т.ч. между разными корнями пространства.
- Выгрузка пространства целиком (`generateSpace`; чекбокс в IDEA, параметр `spaceKey` в MCP).
- Инкрементальная выгрузка: не изменившиеся страницы (по `version.when`) пропускаются.
- Макрос `children` → список локальных ссылок на дочерние страницы.
- Гэп-фичи в обоих форматах: списки-задачи, эмотиконы, подписи к картинкам, метки → `:keywords:`/`tags`,
  Page Properties (`details`).
- Расширенные метаданные в заголовке/frontmatter: url, space, author, created, version.
